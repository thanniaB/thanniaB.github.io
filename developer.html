Handcrafted Code

Yes, AI can do code these days, but why hire an experienced coder when you can ask Claude to do it? Every automation comes with a decline in quality, think about fast fashion or fast food: It may be good enough but it's not the best. A suit bought from a department store will not replace a made-to-measure one, just as a commercial six-pack won't replace craft beer. Every line of code I write is intentional and focused on your product, with deep understanding on what's going on behind the scenes. Vibe coded your way into a pickle? Don't worry, I can take a look into the wires of your code and fix what went wrong.

This page is made in pure HTML and CSS, with a sprinkle of vanilla JS when needed. Why, when most developer go for cool interactive pages using the latest frameworks? Sometimes less is more, all I need is to present some text, if I don't add extra weight it will load faster, plus, using a framework might mean the package will eventually go stale, there's no need for that.
